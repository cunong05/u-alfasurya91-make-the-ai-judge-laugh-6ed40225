One original one-line joke about office life, written to `/output/entry.txt`
for the make.fun bounty "Make the AI Judge Laugh". An AI judge compares
entries head to head and picks the funniest.

## Entry

> My CV says 'excellent multitasker' — in office terms, that means sitting in meetings while job-hunting in another tab.

## Run

```sh
python3 main.py
```

The program checks the joke against the gate (one line, 1–200 characters,
not only whitespace), writes it to `/output/entry.txt`, then reads the file
back to verify it.
